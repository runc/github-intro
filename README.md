# GitHub 快讲 · 片头 & 封面生成器

用**网页动画**实现的视频片头 + 封面生成工具:单文件、零依赖、开箱即用。
舞台固定 1920×1080,全屏录制即为标准 1080p 素材。

## 快速开始

```bash
# 方式一:直接双击 index.html 用浏览器打开
# 方式二:本地起个服务(推荐,避免个别浏览器对 file:// 的限制)
cd oss-channel-intro && npx serve .
```

## 两种模式 & 快捷键

| 按键 | 作用 |
|---|---|
| `SPACE` / `1` | 播放/重播片头动画 |
| `2` / `C` | 进入封面模式(静态构图,用于截图) |
| `S` | 打开/关闭配置面板 |
| `F` | 全屏(录制前按一下) |
| `H` | 隐藏/显示底部提示 |
| `X` | 纯净模式:隐藏提示/角标/⚙(导出封面时用) |

片头节奏(约 9 秒):**终端 `git clone` 打字 → 输出加载完成 → GitHub 风格仓库卡片(star 数滚动)→ 频道名逐字揭示 + 故障闪现 → 标语打字 → 期号条**。

## 配置方式(三选一)

1. **配置面板**:右下角 ⚙ 或按 `S`,所有文字/颜色/特效实时生效;
2. **URL 参数**:所有配置项都支持,例如
   `index.html?mode=cover&ep=EP.02&title=从零手搓一个|【mini-react】&owner=facebook&repo=react&stars=230000&accent=a371f7`
3. **改源码默认值**:文件底部 `DEFAULTS` 对象。

配置完成后点「复制配置链接」,每期一个链接,随用随取。

### 配置项一览

| 参数 | 说明 |
|---|---|
| `channel` / `tagline` / `handle` | 频道名 / 标语 / 账号 |
| `ep` / `title` / `sub` | 期号 / 封面标题 / 副标题 |
| `owner` / `repo` / `desc` / `lang` / `langColor` | 仓库信息 |
| `stars` / `forks` | 会格式化为 `26.8k` |
| `bg` / `bgDeep` / `accent` / `accent2` | 主题色(可不带 `#`) |
| `particles` / `grid` / `glitch` / `scanlines` | 特效开关(`0` 关闭) |
| `speed` | 播放速度 `0.5`–`2` |
| `mode` | `intro`(默认)/ `cover` |
| `fit` | `0` 时关闭自适应缩放(用于精确截图) |
| `clean` | `1` 时隐藏提示/角标/⚙ 等所有界面元素 |
| `shot` | `1` 时整页展开为 1920×1080,配合浏览器整页截图导出像素级封面 |

### 标题排版语法

- `【...】` → 主色高亮(带马克笔底色),如 `快到【离谱】`
- `|` → 强制换行,如 `这个库,让前端动画|快到【离谱】`

## 导出封面(1920×1080 PNG)

1. `index.html?mode=cover&fit=0&clean=1` 打开(1:1 舞台 + 纯净模式);
2. Chrome DevTools → `⌘⇧P` → 输入 **Capture node screenshot** → 选择 `#stage`;
3. 或直接全屏(`F`)后系统截图(`⌘⇧4`)。

仓库内 `cover-example.png` 为示例封面。

## 录制片头视频

1. 打开页面按 `F` 全屏,`H` 隐藏提示;
2. OBS(窗口采集 1920×1080)或 macOS `⌘⇧5` 录屏;
3. 按 `SPACE` 开录,动画约 9 秒,结尾定格在频道名画面,可自由裁剪;
4. 需要慢节奏就在面板把速度调到 `0.8×`。

## 每期工作流建议

改面板参数(期号/标题/仓库)→ 复制配置链接存档 → `fit=0` 导出封面 → 全屏录片头 → 开剪。

## 自定义扩展

- 换 LOGO:在 `#scene-title .t-wrap` 顶部加 `<img>` 即可;
- 换字体:`<head>` 里的 Google Fonts 链接;
- 加新场景:复制一个 `<section class="scene">`,在 `playIntro()` 时间线里插入即可;
- 控制台 API:`KIT.play()` / `KIT.cover()` / `KIT.cfg` / `KIT.apply()`。
